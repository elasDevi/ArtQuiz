PRADO ART CHALLENGE - LOCAL TEST

1. Install Node.js 24 LTS from https://nodejs.org/en/download
2. Extract this ZIP completely. Do not run files inside the ZIP.
3. Windows: double-click START-WINDOWS.bat
   Mac: double-click START-MAC.command (right-click > Open if needed).
   Linux: run node local-test.js from the extracted folder.
4. Your browser opens automatically. Keep the terminal window open.
   Address: http://127.0.0.1:3210

On first launch, npm downloads dependencies; internet is required.
No hosting account or AI key is needed to test the student workflow and manual assessment.
